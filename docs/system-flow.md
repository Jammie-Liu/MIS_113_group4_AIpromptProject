# 系統主線流程

這份文件記錄整個系統的主線流程（登入、練習題、我的課程、競賽）。
**所有組員與 AI 助理修改程式或文件前，都要先讀這份流程，確認改動跟流程沒有衝突；
如果要新增或修改功能，也要同步更新這份文件。**（規則見 [CLAUDE.md](../CLAUDE.md)）

標記說明：
- 「待討論」「還沒確定」：尚未定案的項目
- 「非 MVP」「擴充功能」：第一版不做

- 信箱（需驗證）＋密碼，或登入之後發驗證信就可以登入、免密碼（待討論，參考 IG、Google）

## 二、練習題（LeetCode 式）

- 不是闖關那種，是可以自己選題目的
- 練習完後可以按「下一題」或「回題目頁」
- 題目（簡單、中等、困難）：一個行為、多個行為
- 題目上只顯示名稱與難度，不顯示指標、向度標籤
- 每題只評該題的「適用指標」，不一定涵蓋完整 4D
- 回合制（「回合」＝一段完整對話）：
  - **回合 1（診斷）**：不給提示、不顯示觀察重點；可以「提交」「要提示」「重開」
    - 提交或要提示 → 回合 1 結束並評分
    - 重開或離開不回來 → 視為放棄，不計分，重開後仍是回合 1
  - **回合 2 以後（學習）**：要提示後自動開始；可看階梯提示（提醒 → 模板 → 完整範例），可重開，可提交
- 評分：每個回合結束時，看整段對話評一次（不逐則評分）
- 能力分析：
  - **完成**：任一回合提交的成果達到交付規格，計入解鎖進度（照提示做到也算）
  - **熟練度**：取回合 1 的評分結果，鎖定後不再更動，計入個人能力
- 詳細設計見 `discuss/practice-module` 分支的 `docs/practice-plan.md`（草案）

## 三、我的課程

### 開設

- 開設課程的按鈕，輸入：
  - **必填**：課程名稱、課程介紹、public／private、選擇人數限制、發布時間
  - **選填**：課程結束時間（預設半年）、（價錢）、（標籤）

### 加入

- 課程代碼／QR Code
- 開課的人直接加
  - 老師在課程的學生名單輸入姓名與信箱就能加入；人數已達上限就不能再加（教師端新增）
- private 的課程加入後需經審核
  - 老師在課程的學生名單看到「待審核的加入申請」，可以核准或拒絕；人數已滿不能核准（教師端新增）
  - public 的課程學生用代碼加入後自動通過

### 加入後

- 看到課程、作業（非 MVP）、講義（非 MVP），可進入競賽

## 五、競賽－參賽者（學生端）

### 賽前準備

- 學生從課程頁面點進「競賽連結」
- 或用代碼加入

### 認識組員

- 知道組員（頭貼、名字、帳號）→ 等待開課人開始

### 案例揭露

- 時限開始倒計時、顯示完整案例

### 競賽正式開始

- 題目簡單講議題就好（議題、背景、任務），不用分小題了

### 競賽中

- 一個人就有一個回答的 AI，可以看到同組其他人的 prompt 與結果，互相參考再次修改自己的 prompt
- 可能會看到的教師動作：
  - **提示** → 畫面右下角跳出提示條，幾秒後自動消失，不打斷正在輸入的內容
  - **老師延長時間** → 倒數計時的剩餘時間增加
  - **老師暫停時間** → 倒數也暫停
- 匿名投票誰的結果比較好，當作這組的最終回答（一分鐘）
  - **個人結果**：每位學生該回合聊天室中的最終結果（回答題目的最終解方），也就是組內投票的候選

### 一回合結束

（競賽中「回合」的意思是一整個聊天室的聊天）

- 只有 AI 評分

### 回合數

- 同一題目做二回合（重複練習 → 找新的答案解方）

### 競賽結束（所有回合結束）

- 互評：AI 評分、小組留言其他組的最終回答、老師評分（根據 AI 評分加／扣分）
- 公布前三名，自己組才能看到自己組的總分、名次、互評、老師評價

### 資料回存

- 寫入學生的競賽紀錄、更新個人 4D 能力報表

## 六、競賽－發起者（教師端）

### 賽前準備

- 老師進入某個授課群組，點選該群組
- 點下「發起競賽」
- 填寫基本設定：
  - **題庫來源**：題目簡單講議題就好，不用分小題了
  - **＋回合設定**：預設二回合，老師可調整
  - **時間限制**：預設 20 分鐘，老師可調整；為一回合的時間限制
  - **發布時間**：這場競賽會顯示在學生端的時間點（可設未來時間，排程發布）
  - **其他說明**：老師可填的補充文字
- 按下「完成」
- 系統在設定的發布時間一到，把這場競賽的連結放進對應課程的學生端頁面
- 假設學生已經分好組（＋系統隨機分組），系統會寫學生現在是第幾組
  - 老師在課程的「小組名單」可以看到分組（預設系統隨機分組），也可以手動拖拉同學換組、新增小組；調整後，下一場競賽使用新的分組（教師端新增）

### 後台監控

- 顯示基本資料：
  - 目前是第幾回合（第 N／共 M 回合）與每個回合的狀態（教師端新增）
  - 剩餘時間
  - 老師可視情況按「增加時間」、「暫停時間」調整剩餘時間（只有回合進行中可以）
  - 各隊目前進度，點進去看得到：
    - 該隊各成員的完整聊天室
    - 可傳送提示條，針對該隊或群發，幾秒後自動消失
- 回合怎麼推進（教師端新增，**待與組員確認**）：
  1. **進行中**：每回合時限倒數
  2. **匿名投票**：回合時間到後，組內匿名投票選出最終回答（一分鐘）
  3. **評分**：投票完成後，評分 AI 評分
  4. **回合結束**：老師按「開始第 N 回合」才進入下一回合（下一回合開始時，學生的對話記憶清空）；最後一回合評分完，顯示「前往評分」
  - 老師可以按「結束第 N 回合」，提前結束目前這一回合（直接進入匿名投票）
  - 老師可以按「結束整場並評分」，提前結束整場競賽，直接進入結果頁面
- 按下「競賽結束」會跳到結果頁面，或時間到自動結束

### 一回合結束

- 只有 AI 評分

### 回合數

- 同一題目做二回合（重複練習 → 找新的答案解方）

### 競賽結束（所有回合結束）

- 互評：AI 評分、小組留言其他組的最終回答（純文字留言，不計分）、老師評分（可選，＋跳過評分的按鈕）
- 老師評分的畫面（教師端新增，細節規則見 [scoring-design.md](scoring-design.md) 七、八）：
  - 每一隊可以看到：組內投票選出的最終回答、各回合的解方分數與組 4D 分數、每位組員的個人 4D 與各維度評語、評分 AI 的標記（不確定、疑似錯誤、未說明來源、幻覺扣分、盡-1 扣分，**優先列出**）
  - 老師不能改 AI 的判斷，只能在每隊的「排名分數」上加減分（±10 分以內）；**有加減分就必須寫理由**，理由會顯示在該隊的「老師評價」
  - 頁面上方有「確認評分」與「跳過評分」兩個按鈕：有隊伍加減分但沒寫理由時，「確認評分」不能按；「跳過評分」＝所有隊伍調整 0 分
  - 按下其中一個之後，才計算最終排名並公布結果，公布後不能再修改老師評分
- 公布前三名，自己組才能看到自己組的總分、名次、互評、老師評價

### 資料回存

- 系統把這個題目的「平均 4D 分數、高標、低標、中位數、標準差」寫入課程資料庫（紀錄該課程中學生的 4D 能力成長）
  - 老師公布結果（確認評分或跳過評分）的同時寫入，並把這場的名次一起寫進課程的過往競賽紀錄
  - 老師在課程的「4D 能力成長」可以看到各場競賽的班級平均與進退，點一場看完整統計（教師端新增）

## 七、題庫管理（教師端，新增）

- 題庫依「難度」（青銅、白銀、黃金、鑽石）與「分類」整理，老師從側邊欄的「題庫管理」選「依分類」或「依難度」查看
- 系統內建題庫只能看，不能修改或刪除；老師自己建立的題庫可以新增、修改、刪除，並設定公開（所有教師可用）或僅本人可用
- 分類可以由老師自行新增、刪除；刪除分類時，裡面的題庫不會被刪掉，會移到「未分類」
- 發起競賽時，老師先選分類，再從該分類挑一個題目（沒有題目的分類不會出現）
