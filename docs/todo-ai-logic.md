## 一、我的待辦

### AI 邏輯

- [ ] **寫各角色的 system prompt**：6 個角色（練習／競賽 × 回答、評分、偵測），加上兩種額外用法：
  產生基準答案（競賽回答 AI）、每回合給老師的改善建議（競賽評分 AI）。建議從最複雜的競賽評分 AI 開始。
- [ ] **定各角色輸出的 JSON 格式**：評分 AI、偵測 AI、改善建議都用結構化輸出，欄位要跟芷琳（競賽後端）、
  筠靈（教學後端）一起定，定案後寫進 API 規格。
- [ ] **驗證判斷卡**：準備幾段模擬對話（做得好、普通、很差各幾段），AI 評一次、人工評一次，比對準不準；
  順便看實際 token 用量，估算費用（見 `ai-api-setup.md` 第八節）。
- [ ] **增加競賽題庫**：目前只有「動物表演」一題。每題要有議題、背景、任務、利害關係人、主要面向。
  - 議題來源可以參考公共議題網站（例如公共政策網路參與平台、新聞專題報導）。
  - 建議用「找議題當靈感、自己改寫背景」的方式，不要直接複製或大量自動爬取網站內容（可能違反網站使用規範或著作權）。
  - 出好的題目要跑一次基準答案，確認不是所有面向都被基本提問答完（太簡單的題目不能發布）。

### 跟教授一起處理

- [ ] **購買 API**（見 `ai-api-setup.md` 第二、九節）：誰建立組織帳號、誰當管理者、儲值金額與花費上限。
- [ ] **決定每個角色用的模型**：先全部用 Opus 5.5，驗證判斷卡後再決定偵測 AI 等是否換小模型。

### 不是我主責、但要知道

- 練習題庫（每題的適用指標、交付規格、三級提示）主要由**筠靈**負責；AI 邏輯的部分（指標怎麼評）照
  `scoring-design.md` 第九節，有疑問再找我。
