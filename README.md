# MIS_113_group4_AIpromptProject

AI 提示工程教學遊戲（學生端練習 + 教師端競賽監控）。

- 專案規劃結構：[docs/architecture.md](docs/architecture.md)
- **每次重大修改都會記錄在 [docs/CHANGELOG.md](docs/CHANGELOG.md)**——不論你是人還是
  AI 助理，開始改程式碼前請先看這份檔案，改完後也請照裡面的格式補一則紀錄。
- 原始 UI 設計原型（純 HTML，不是正式程式碼）：`frontend/src/prototypes/`

## 前端怎麼跑起來

```bash
cd frontend
npm install
npm run dev
```

需要先在電腦上裝好 [Node.js](https://nodejs.org)（LTS 版本，會順便裝好 npm）。
